# Contributing

Contributions are welcome when they keep the public template reusable and
legally redistributable.

1. Create a branch and install dependencies with `npm ci`.
2. Keep campaign examples fictional and original.
3. Do not submit publisher rules text, adventure content, copyrighted maps,
   unlicensed artwork, personal transcripts or credentials.
4. Run `npm run build` and the transcriber tests before opening a pull request.
5. Explain user-visible changes and include screenshots for visual work.

By contributing, you confirm that you have the right to license your
contribution under this repository's MIT License.
